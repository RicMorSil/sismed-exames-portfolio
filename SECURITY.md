# Repository security

This repository is intended exclusively for demonstration purposes and does not contain the SISMED EXAMES source code.

## Before every publication

- Confirm that no PHP, SQL, ZIP, backup, or configuration files are included.
- Search for passwords, usernames, email addresses, IP addresses, tokens, and keys.
- Use fictional patients and professionals in every screenshot.
- Remove administrative URLs and server information from images.
- Do not publish demonstration-environment credentials.
- Do not include the detailed database structure or complete internal rules.

## Reporting a vulnerability

If you identify sensitive information in this material, contact the author privately. Do not open a public issue containing credentials, personal data, or details that could facilitate exploitation.
