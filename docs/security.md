# Security and privacy

The project addresses credential protection, access segregation, traceability, and appropriate data handling as part of its architecture.

## Implemented controls

- Password hashing
- Prepared statements
- CSRF protection
- Session expiration
- Secure cookie settings
- Role-based access control
- Action auditing
- Production error messages that do not expose technical details
- HTTPS in the published environment

## Demonstration environment

The demonstration environment must use a separate database, fictional data, a non-administrative user, and restrictions on critical operations.

No real patient, employee, or healthcare-unit data may appear in this repository or in the public demonstration.
