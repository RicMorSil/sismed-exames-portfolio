# Features

## Patients and collections

Allows users to find patients, register collections, and organize the exams associated with each service.

## Labels

Generates labels according to the operational workflow and the laboratories involved, supporting the correct identification of collected specimens.

## Reports and dashboard

Presents consolidated operational information for activity monitoring and management support.

## Access roles

Restricts functions according to each user's role, separating administrative, management, and operational responsibilities.

## Audit trail

Records relevant actions to improve traceability across the system.

This document describes general capabilities and intentionally omits detailed internal rules.
