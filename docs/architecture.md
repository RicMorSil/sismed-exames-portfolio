# Architecture

SISMED EXAMES uses a web architecture based on PHP, Apache, and MySQL. The interface is built with HTML, CSS, and JavaScript, while business-rule processing and database access run on the server.

## Presented components

- **Web interface:** forms, searches, reports, and dashboard.
- **Application layer:** validation, authentication, business rules, and access control.
- **Database:** persistence of operational and audit records.
- **Printing:** integration with thermal printers through compatible local tools.

Internal details, source code, the complete database diagram, and infrastructure settings have been omitted for security and intellectual-property protection.
