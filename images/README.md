# Portfolio images

Add only screenshots prepared for public presentation to this folder.

## Suggested filenames

- `login.png`
- `dashboard.png`
- `collection.png`
- `labels.png`
- `report.png`

## Checklist before adding an image

- Use fictional names and information only.
- Hide email addresses, IP addresses, identifiers, and employee names.
- Do not display credentials, configuration files, databases, or hosting dashboards.
- Crop the browser bar if it reveals administrative pages.
- Apply a discreet watermark: `SISMED EXAMES — PORTFOLIO`.
- Inspect the image at full size before publishing it.
